Vocabulary

independent variable
The input quantity. It changes on its own or you choose it — often time. It goes on the x-axis.
dependent variable
The output quantity. Its value depends on the input. It goes on the y-axis.
increasing
Reading left to right, the graph goes up. The output gets bigger.
decreasing
Reading left to right, the graph goes down. The output gets smaller.
constant
The graph is flat. The output stays the same.
zero (x-intercept)
An input that makes the output 0. The graph touches or crosses the x-axis there.
Formal: x = a is a zero of f if f(a) = 0.
y-intercept
Where the graph crosses the y-axis. It is the output when the input is 0.
Formal: The point (0, f(0)).
relative maximum
A peak: an output higher than every point near it on both sides.
Formal: f(c) is a relative maximum if f(c) ≥ f(x) for all x near c.
relative minimum
A valley: an output lower than every point near it on both sides.
Formal: f(c) is a relative minimum if f(c) ≤ f(x) for all x near c.
interval of increase
The x-values where the graph is increasing. Write it with parentheses: (−2, 1).
interval of decrease
The x-values where the graph is decreasing. Write it with parentheses: (1, 4).
domain
All the inputs (x-values) the function uses.
range
All the outputs (y-values) the function gives.

Notes — Reading Key Features

1 · Read every feature from one graph

Intervals use x-values only. Read left to right and write where the piece starts and stops on the x-axis. Use parentheses for increasing, decreasing and constant: the turning points themselves are not inside. Domain and range keep brackets [ ] when the endpoint dots are closed.
Endpoints are not relative maximums or minimums. A relative maximum needs lower points on both sides. The endpoint (−6, −4) is the lowest point, but it is not a relative minimum.

2 · Features tell a story

Drone flight
A drone takes off. Its height h (meters) depends on the time t (seconds).
Independent variable: time t · Dependent variable: height h
Increasing (0, 2) and (4, 6): the drone is climbing.
Constant (2, 4): it hovers at 4 m.
Relative maximum 8 at t = 6: its highest point is 8 m, 6 s after takeoff.
Decreasing (6, 10): it is coming down.
Zeros t = 0 and t = 10: it is on the ground at takeoff and lands at 10 s.
y-intercept (0, 0): it starts at 0 m.
Domain [0, 10] seconds · Range [0, 8] meters

E2Explain why a function can have several relative maximums but only one greatest value in its range. Use the graph of k in #7.
Check answer
A relative maximum only has to be higher than the points near it. k has peaks 3 (at x = −4) and 5 (at x = 1). Both are relative maximums, but only 5 is the greatest output of the whole function.
E3Can a function have two zeros? Can it have two y-intercepts? Explain.
Check answer
Two zeros: yes — g in #1 has three. Two y-intercepts: no — both would be on the line x = 0, so the input 0 would have two outputs. That fails the vertical line test.
