Vocabulary

vertex form
y = a·f(x − h) + k. The numbers a, h and k tell how the parent changed. (h, k) is the vertex or starting point.
Formal: y = a·f(x − h) + k, where f is a parent function; a gives the stretch, compression or reflection; h and k give the translation.
vertical stretch
The graph gets taller and skinnier. Every y-value is multiplied by a number bigger than 1.
vertical compression
The graph gets shorter and wider. Every y-value is multiplied by a number between 0 and 1.
reflection across the x-axis
The graph flips upside down over the x-axis. It happens when a is negative.

− in frontreflection across the x-axis (flips upside down)

0 < a < 1vertical compression by a (shorter, wider)
h insidehorizontal translation — sign looks opposite
k outsidevertical translation

2 · Graph in two moves

Move 1: plot the vertex or starting point (h, k). Move 2: use the parent's pattern with a. If a is negative, go down instead of up.

Example 1
y = −2|x − 1| + 3
Vertex (1, 3). a = −2: over 1, down 2.
Points (−1, −1), (0, 1), (2, 1), (3, −1).
Domain: all real numbers · Range: y ≤ 3

3 · Describe

Name them in this order: reflection → stretch or compression → left/right → up/down.

Example 4
y = −⅓|x + 6| + 2
Reflection across the x-axis, vertical compression by ⅓, left 6, up 2. Vertex (−6, 2).

4 · Write the equation

Example 5 — from a description
Absolute value, reflected, stretched by 2, right 1, down 4.
Reflected and stretched by 2 → a = −2. Right 1 → x − 1. Down 4 → − 4.
y = −2|x − 1| − 4
Example 6 — from a graph
U shape → x². Vertex (2, −3), so y = a(x − 2)² − 3.
Use a second point, (3, −1): a(3 − 2)² − 3 = −1 → a − 3 = −1 → a = 2.
y = 2(x − 2)² − 3
Quick check: over 1 from the vertex, the graph goes up 2 = a. ✓
