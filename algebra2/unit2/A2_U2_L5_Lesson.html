Two graphs side by side. Step through g(f(x)) one move at a time.

  3. Is g(f(2)) the same as f(g(2))?
  4. Open Graph pair 2 (not swapped). Start at x = 3 and step. What happens? Why?
  5. In g(f(x)), which function does the tool use first? Write a rule in your own words.
Check after you compare
1. f(2) = 2, then g(2) = 1. So g(f(2)) = 1.
2. g(2) = 1, then f(1) = 3. So f(g(2)) = 3.
3. No. 1 ≠ 3. The order matters.
4. f(3) = −4. The graph of g only covers x = −3 to x = 5, so −4 is not in the domain of g. g(f(3)) is undefined.
5. Inside first. Find f(x) first. Its output is the input of g.

Vocabulary

composition of functions
Using the output of one function as the input of the next function. g(f(x)) is read "g of f of x."
Formal: The composition of g and f is the function whose rule is g(f(x)). It is defined only where f(x) is in the domain of g.
inner function
The function that works first — the one inside the parentheses. In g(f(x)), f is the inner function.
outer function
The function that works second — it takes the inner function's output. In g(f(x)), g is the outer function.
input
The value you put into a function — the x-value.
output
The value the function gives back — the y-value.
domain
All the inputs a function can take. On a graph: every x-value the graph covers. In a table: the x-row.

Notes

1 · Inside first

g(f(x))

Start inside the parentheses. Find the inner output f(x). That output becomes the input of the outer function g.

x—f→f(x)—g→g(f(x))

2 · From two graphs

Example 1
Find g(f(3)).
Inner: go to x = 3 on the graph of f. f(3) = −2.
Outer: go to x = −2 on the graph of g. g(−2) = 2.
So g(f(3)) = 2.

3—f→−2—g→2

Example 1b — switch the order
Find f(g(3)).
Inner: g(3) = 3. Outer: f(3) = −2. So f(g(3)) = −2.
Order matters. g(f(3)) = 2 but f(g(3)) = −2.

Example 2
Find g(f(1)).
Inner: in f's table, x = 1 gives f(1) = 2.
Outer: find 2 in the x-row of g's table. g(2) = 0. So g(f(1)) = 0.
Example 2b — not in the domain
Find f(g(1)).
Inner: g(1) = −3.
Outer: −3 is not in the x-row of f's table. f(g(1)) is undefined — not in the domain of f.
Look up the inner output in the outer function's x-row (its inputs), never its output row.

4 · Mixed: table or graph + equation

Example 3
Use f's table above and g(x) = 2x − 3.
g(f(−2)): f(−2) = 3, then g(3) = 2(3) − 3 = 3.
f(g(2)): g(2) = 2(2) − 3 = 1, then f(1) = 2 (from the table).
Example 4
Use the graph of g and h(x) = x² − 1.
g(h(−2)): h(−2) = (−2)² − 1 = 3, then g(3) = 3 (from the graph).
h(g(5)): g(5) = −1, then h(−1) = (−1)² − 1 = 0.

5 · The same function twice

Example 5
f(f(4)) from the graph: f(4) = −4, then f(−4) = 0.
f(f(−1)) from f's table: f(−1) = 1, then f(1) = 2.
Use the same graph (or table) twice.

A1C(t) is the temperature in °C at t hours after midnight. F(C) converts °C to °F.
t (hours)68101214
C(t) (°C)510152025
C (°C)510152025
F(C) (°F)4150596877
a) Find F(C(10)) and explain what it means.
b) Find F(C(14)).
c) Explain why C(F(10)) makes no sense.
Check answer
a) C(10) = 15, F(15) = 59. At 10 a.m. the temperature is 59 °F.
b) C(14) = 25, F(25) = 77 °F (at 2 p.m.).
c) F(10) = 50 is a temperature. C's inputs are times (6 to 14), so 50 is not in the domain of C.
A2n(d) is the number of tickets sold on day d of a play. Each ticket costs $12, so the revenue is R(n) = 12n dollars.
d (day)1234
n(d) (tickets)40557085
a) Find R(n(3)) and explain what it means.
b) On which day was the revenue $1,020?
Check answer
a) n(3) = 70, R(70) = 12(70) = 840. On day 3 the revenue was $840.
b) 12n = 1020 → n = 85. n(d) = 85 on day 4.
