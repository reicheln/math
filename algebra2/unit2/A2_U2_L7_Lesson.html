Vocabulary

parent function
The simplest function in a family. Today: y = |x|, y = x², y = √x.
Formal: The most basic function of a family; every other member is the parent moved or reshaped.
translation
A slide. Every point moves the same distance in the same direction. The shape does not change.
vertical translation
A slide up or down. y = f(x) + k moves the graph up k (down if k is negative).
horizontal translation
A slide left or right. y = f(x − h) moves the graph right h (left if h is negative).
vertex
The point of the V (|x|) or the bottom or top of the U (x²). For the parents it is (0, 0).
starting point
The point where a √x graph begins. For y = √x it is (0, 0).
domain
All the x-values the graph uses.
range
All the y-values the graph uses.

Notes

1 · Three parent functions

y = |x|

Key points: (0, 0), (−2, 2), (−1, 1), (1, 1), (2, 2)
Vertex: (0, 0)
Domain: all real numbers
Range: y ≥ 0

y = x²

Key points: (0, 0), (−2, 4), (−1, 1), (1, 1), (2, 4)
Vertex: (0, 0)
Domain: all real numbers
Range: y ≥ 0

y = √x

Key points: (0, 0), (1, 1), (4, 2), (9, 3)
Starting point: (0, 0)
Domain: x ≥ 0
Range: y ≥ 0

√x starts at (0, 0) and only goes right: you can't take the square root of a negative number.

2 · Up and down: y = f(x) + k

+ k outside → up k  ·  − k outside → down k

Adding outside changes every y-value. That is a vertical translation.

Example 1
y = x² − 4
Every y-value of x² goes down 4.
Down 4. Vertex (0, −4).

3 · Left and right: y = f(x − h)

(x − 2) → right 2  ·  (x + 3) → left 3

Changing inside moves the graph sideways. That is a horizontal translation. The sign inside looks opposite.

Example 2
y = |x + 3|
Left 3. Vertex (−3, 0).
Why opposite? The vertex is where the inside equals 0. x + 3 = 0 → x = −3. So the vertex sits at x = −3: left 3.

4 · Both at once: y = f(x − h) + k

y = f(x − h) + k → vertex or starting point at (h, k)

Example 3
y = (x − 3)² + 1
Right 3, up 1. Vertex (3, 1).
Draw the parent's shape from there: over 1 up 1, over 2 up 4.
Example 4
y = √(x + 4) − 2
Left 4, down 2. Starting point (−4, −2).
From there: over 1 up 1, over 4 up 2.

5 · Domain and range after a translation

EquationVertex / starting pointDomainRange
y = x² − 4(0, −4)all real numbersy ≥ −4
y = |x + 3|(−3, 0)all real numbersy ≥ 0
y = (x − 3)² + 1(3, 1)all real numbersy ≥ 1
y = √(x + 4) − 2(−4, −2)x ≥ −4y ≥ −2

|x| and x² always have domain all real numbers. The range starts at k. For √x, the domain starts at h too.

6 · Write the equation

Example 5 — from a description
Square root, left 2, up 3.
Left 2 → inside is x + 2. Up 3 → + 3 outside.
y = √(x + 2) + 3
Example 6 — from a graph
V shape → absolute value. Vertex (1, −4): h = 1, k = −4.
y = |x − 1| − 4
Check a point: x = 3 gives |3 − 1| − 4 = −2. ✓
