Vocabulary

function operations
Adding, subtracting, multiplying, or dividing two functions to make a new function.
Formal: For functions f and g: f + g, f − g, f · g, and f/g.
sum (of functions)
Add the two outputs. Written (f + g)(x).
Formal: (f + g)(x) = f(x) + g(x)
difference (of functions)
Subtract the second output from the first. Written (f − g)(x). Order matters.
Formal: (f − g)(x) = f(x) − g(x)
product (of functions)
Multiply the two outputs. Written (f · g)(x).
Formal: (f · g)(x) = f(x) · g(x)
quotient (of functions)
Divide the first output by the second. Written (f/g)(x). The bottom can't be 0.
Formal: (f/g)(x) = f(x)/g(x), where g(x) ≠ 0

Notes

1 · Four function operations

Sum

(f + g)(x)
= f(x) + g(x)

Difference

(f − g)(x)
= f(x) − g(x)

Product

(f · g)(x)
= f(x) · g(x)

Quotient

(f/g)(x) = f(x)g(x)
g(x) ≠ 0

Each one makes a new function. Do the operation on the rules, then simplify.

2 · Sum and difference

f(x) = 2x² − 3x + 1    g(x) = x² + 4x − 5

Example 1 — sum
(f + g)(x) = (2x² − 3x + 1) + (x² + 4x − 5)
Combine like terms: 3x² + x − 4
Example 2 — difference
(f − g)(x) = (2x² − 3x + 1) − (x² + 4x − 5)
= 2x² − 3x + 1 − x² − 4x + 5
= x² − 7x + 6
Distribute the negative to every term of g(x). The wrong way changes only the first sign: 2x² − 3x + 1 − x² + 4x − 5 = x² + x − 4 ✗

4 · Quotient

Write f(x) over g(x). Leave it as a fraction unless it factors. Always say which x makes g(x) = 0.

Example 5 — leave as a fraction
f(x) = 2x + 1, g(x) = x − 4
(f/g)(x) = 2x + 1x − 4, x ≠ 4 (because g(4) = 0)
Example 6 — it factors
f(x) = x² − 9, g(x) = x + 3
(f/g)(x) = x² − 9x + 3 = (x + 3)(x − 3)x + 3 = x − 3, x ≠ −3

5 · Evaluate two ways

Use f(x) = 2x² − 3x + 1 and g(x) = x² + 4x − 5 from Examples 1–2.

Way 1 — outputs first
f(3) = 18 − 9 + 1 = 10
g(3) = 9 + 12 − 5 = 16
(f − g)(3) = 10 − 16 = −6
Way 2 — new rule
(f − g)(x) = x² − 7x + 6
(f − g)(3) = 9 − 21 + 6 = −6
Example 7 — quotient
(f/g)(2) = f(2)g(2) = 37. But g(1) = 0, so (f/g)(1) has no value. x = 1 is not allowed.

Application

Profit = revenue − cost. Revenue is the money coming in. Cost is the money going out.

A1The yearbook club orders n yearbooks. Printing costs P(n) = 12n + 400 dollars. Shipping costs S(n) = 2n + 75 dollars. Each book sells for $25, so revenue is R(n) = 25n.
a) Write the total cost T(n) = (P + S)(n). Find T(150).
b) Write the profit (R − T)(n).
c) What is the fewest books they must sell to make a profit?
Check answer
a) T(n) = 14n + 475; T(150) = $2,575
b) 25n − (14n + 475) = 11n − 475
c) 11n − 475 > 0 → n > 43.2, so 44 books (43 books: −$2; 44 books: $9)
A2A bakery sells x dozen cupcakes a day at $30 a dozen: R(x) = 30x. Its daily cost is C(x) = x² + 5x + 100. Write the profit function P(x) = (R − C)(x). Find P(10) and P(3). Explain each in a sentence.
Check answer
P(x) = 30x − x² − 5x − 100 = −x² + 25x − 100
P(10) = 50: selling 10 dozen makes a $50 profit.
P(3) = −34: selling 3 dozen loses $34.
A3A coffee cart lowers its price by x dollars. The price is p(x) = 20 − x and the number sold is q(x) = 10 + 5x. Revenue = price × number sold. Write R(x) = (p · q)(x). Find R(4) two ways.
Check answer
R(x) = (20 − x)(10 + 5x) = −5x² + 90x + 200
p(4) · q(4) = 16 · 30 = 480; −5(16) + 90(4) + 200 = 480. Revenue is $480.
