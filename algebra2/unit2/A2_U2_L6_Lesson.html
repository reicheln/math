Vocabulary

absolute value
How far a number is from 0. It is never negative. |−5| = 5 and |5| = 5.
Formal: |x| = x if x ≥ 0, and |x| = −x if x < 0.
distance
How far apart two numbers are on a number line. A distance is 0 or positive — never negative.
Formal: |x − h| is the distance between x and h.
solution set
All the answers that make the equation true, written in braces: {−2, 2}.
no solution
No number makes the equation true. Also written ∅.
isolate
Get something alone on one side of the equation. Isolate the absolute value before you split into two equations.

Notes

1 · Absolute value is a distance

Example 1
Solve |x| = 2.
Which numbers are 2 away from 0? x = 2 or x = −2. Solution set {−2, 2}.

2 · Something inside the bars

Example 2
Solve |x + 1| = 8.
The inside, x + 1, is 8 away from 0. So it equals 8 or −8.
x + 1 = 8  or  x + 1 = −8
x = 7    or  x = −9
Solution set {−9, 7}. Both are 8 away from −1.

3 · Isolate first

Steps
  1. Isolate the absolute value: get |…| alone on one side.
  2. Set the inside equal to the positive value and the negative value.
  3. Solve both equations.
  4. Write the solution set { , }.
Example 3
Solve 3|x| + 6 = 24.
3|x| = 18  (subtract 6)
|x| = 6  (divide by 3)
x = 6  or  x = −6
Solution set {−6, 6}.
Example 4
Solve −2|x + 3| + 8 = −14.
−2|x + 3| = −22  (subtract 8)
|x + 3| = 11  (divide by −2)
x + 3 = 11  or  x + 3 = −11
x = 8     or  x = −14
Solution set {−14, 8}.
Do not split too early. In Example 4, −2|x + 3| + 8 = −14 does not become x + 3 = −14. Isolate first.

4 · Special cases

Example 5 — no solution
Solve |x| = −6.
A distance cannot be negative. No number is −6 away from 0.
Answer: no solution (∅).
Example 6 — one solution
Solve |x − 4| = 0.
Only one number is 0 away from 4.
x − 4 = 0 → x = 4. Solution set {4}.
Check the sign after you isolate. Positive → two solutions. 0 → one solution. Negative → no solution.

5 · Check by graphing

Unit 1: a solution is where two graphs cross. Graph each side of the equation.

Example 7
|x − 3| = 4
y = |x − 3| and y = 4 cross at (−1, 4) and (7, 4). The x-values −1 and 7 are the solutions.
Example 8

The line y = −6 never touches the V. No solution.

Application

Write an absolute value equation. Solve it. Answer in a sentence.

A1A machine part must be 25 mm long. A part passes if its length is within 0.2 mm of 25 mm. Write and solve an equation for the shortest and longest lengths that pass.
Check answer
|x − 25| = 0.2 → x − 25 = 0.2 or x − 25 = −0.2 → x = 25.2 or x = 24.8.
The shortest part that passes is 24.8 mm. The longest is 25.2 mm.
A2A thermostat is set to 68°F. The room temperature swings 3° above or below 68°F. Write and solve an equation for the lowest and highest temperatures.
Check answer
|t − 68| = 3 → t = 71 or t = 65.
The lowest temperature is 65°F. The highest is 71°F.

Extension — Green

E1Write an absolute value equation with solutions −2 and 8.
Check answer
The center is halfway: (−2 + 8) ÷ 2 = 3. Each is 5 away from 3. |x − 3| = 5.
E2Without solving, explain why |x| + 5 = 2 has no solution.
Check answer
|x| is never negative, so |x| + 5 is always 5 or more. It can never equal 2. (Isolating gives |x| = −3.)
E3For what value of c does |x − 4| = c have exactly one solution? Explain.
Check answer
c = 0. Only x = 4 is 0 away from 4. Positive c gives two solutions; negative c gives no solution.
