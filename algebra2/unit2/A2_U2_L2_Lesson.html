Vocabulary

function notation
A way to name a function and show its input: f(x) = 2x + 7. Read f(x) as "f of x."
Formal: f(x) denotes the output of f corresponding to the input x.
input
The value you put into a function — the x-value. It comes from the domain.
output
The value the function gives back — the y-value, f(x). It is in the range.
evaluate
Replace the input with a number and simplify to find the output.

Notes

1 · From y = to f(x) =

y = 2x + 7  →  f(x) = 2x + 7

f is the name of the function, x is the input, and f(x) is the output. f(x) does not mean f times x. The name tells you which rule to use when there is more than one function.

2 · Evaluate from an equation

Example 1
If f(x) = 2x + 7, find f(−3).
Replace every x with (−3): f(−3) = 2(−3) + 7 = 1. So the point (−3, 1) is on the graph of f.
Example 2 — watch the square
If h(x) = x² − 4x, find h(−2).
Use parentheses: h(−2) = (−2)² − 4(−2) = 4 + 8 = 12.
Always put the input in parentheses. (−2)² = 4, but −2² = −4.

3 · Evaluate from a table or a graph

p(3) = 10: find 3 in the input row, read the output.

k(−2) = 3: go to x = −2, move up to the graph, read the y-value.

4 · Solve f(x) = a number

Now the output is given and you find the input.

Example 3 — equation
If f(x) = 4x − 5, find x when f(x) = 23.
4x − 5 = 23 → 4x = 28 → x = 7.
Example 4 — graph
Using the graph of k above, find x when k(x) = 3.
Draw the horizontal line y = 3. It meets the graph at x = −2 and x = 4. A function can reach the same output more than once.

5 · Function notation in context

Example 5
A gym charges a $45 sign-up fee plus $30 per month. The total paid after t months is m(t) = 45 + 30t.
m(6) = 45 + 30(6) = 225. Meaning: after 6 months, the total paid is $225.
m(t) = 405 → 30t = 360 → t = 12. Meaning: the total reaches $405 after 12 months.

Application

Define the variables, write or use the function, solve, then interpret the answer in a sentence.

A1A streaming service charges $12 to join plus $9 per month. Write a function c(m) for the total cost after m months. Find c(8) and explain what it means. When does the total reach $129?
Check answer
c(m) = 12 + 9m
c(8) = 84: after 8 months the total paid is $84.
12 + 9m = 129 → m = 13: the total reaches $129 after 13 months.
A2Two friends are saving money. After w weeks, Ava has A(w) = 40w + 120 dollars and Ben has B(w) = 25w + 300 dollars. Solve A(w) = B(w) and explain what the answer means.
Check answer
40w + 120 = 25w + 300 → 15w = 180 → w = 12.
After 12 weeks they have the same amount: A(12) = B(12) = $600.
A3For the streaming service in A1, what is a reasonable domain for c(m)? Is c(m) discrete or continuous?
Check answer
m = 0, 1, 2, 3, … (whole numbers of months). Discrete — you pay by the whole month.

Extension — Green

E2Let g(x) = x². Is g(a + b) always equal to g(a) + g(b)? Test a = 1, b = 2.
Check answer
g(3) = 9 but g(1) + g(2) = 1 + 4 = 5. No. (a + b)² = a² + 2ab + b².
E3Write a linear function f with f(0) = 4 and f(2) = 10.
Check answer
Slope = (10 − 4)/(2 − 0) = 3, so f(x) = 3x + 4.
