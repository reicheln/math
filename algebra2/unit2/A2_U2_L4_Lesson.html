Discovery

Two machines in a row (pods, 10 min)

Function Machine
A number goes into f. Its output goes straight into g.
Open

f(x) = x + 1  ·  g(x) = 2x + 3

  1. Open the Function Machine. Pick the first rule pair: f(x) = x + 1 and g(x) = 2x + 3.
  2. Drop in 1, 2, and 3. On scratch paper, copy the table: x | f(x) | g(f(x)).
  3. Before you run 4, predict the final output. Then run it and check.
  4. Press Swap order so g goes first. Run 1, 2, 3, 4 again. Compare the two tables.
  5. Does the order of the machines change the final output?
What you should see
f then g: 1 → 2 → 7, 2 → 3 → 9, 3 → 4 → 11, 4 → 5 → 13.
g then f: 1 → 5 → 6, 2 → 7 → 8, 3 → 9 → 10, 4 → 11 → 12.
The order changes the answer. Every final output is 1 less when g goes first.

Vocabulary

composition of functions
Using the output of one function as the input of the next function.
Formal: The composition of g and f is the function whose rule is g(f(x)).
composite function
The single new function you get from a composition, such as g(f(x)) = 2x + 5.
inner function
The function that works first — the one inside the parentheses. In g(f(x)), f is the inner function.
outer function
The function that works second — it takes the inner function's output. In g(f(x)), g is the outer function.
(g ∘ f)(x)
Another way to write g(f(x)). Read it "g of f of x." The small circle means composition, not multiplication.
Formal: (g ∘ f)(x) = g(f(x))

Notes

1 · The output of one function becomes the input of the next

x → f → f(x) → g → g(f(x))
x123
f(x)234
g(f(x))7911

g(2) = 2(2) + 3 = 7 · g(3) = 9 · g(4) = 11

f(x) = x + 1 and g(x) = 2x + 3.
Fill the f(x) row first. Then use each f(x) as the input for g. The f(x) row is the handoff.

2 · Notation: work from the inside out

(g ∘ f)(x) = g(f(x))

Read it "g of f of x." f is the inner function, so it works first. g is the outer function, so it works second. The ∘ is not multiplication.

Example 1 — a number
f(x) = x + 1 and g(x) = 2x + 3. Find (g ∘ f)(4).
Inside first: f(4) = 4 + 1 = 5.
Then outside: g(5) = 2(5) + 3 = 13.

3 · Algebra: replace x with the whole inner function

Example 2
f(x) = x + 1 and g(x) = 2x + 3. Find g(f(x)).
Write the outer rule: g(x) = 2x + 3.
Replace x with (x + 1): g(f(x)) = 2(x + 1) + 3
Simplify: = 2x + 2 + 3 = 2x + 5.
Check with Example 1: 2(4) + 5 = 13. ✓
Example 3 — a quadratic outer function
f(x) = x² and g(x) = x − 3. Find f(g(x)).
Outer rule: f(x) = x². Replace x with (x − 3): f(g(x)) = (x − 3)²
= (x − 3)(x − 3) = x² − 6x + 9.
Always use parentheses around the inner function. 2x + 1 + 3 is wrong; 2(x + 1) + 3 is right.

4 · Order matters

g(f(x)) — f first
= 2(x + 1) + 3
= 2x + 5
g(f(4)) = 13
f(g(x)) — g first
= (2x + 3) + 1
= 2x + 4
f(g(4)) = g(4) + 1 = 11 + 1 = 12

Same two functions, different order, different composite function. In general, f(g(x)) ≠ g(f(x)).

Example 4
f(x) = x² and g(x) = x − 3.
g(f(x)) = x² − 3, so g(f(5)) = 25 − 3 = 22.
f(g(x)) = x² − 6x + 9, so f(g(5)) = (5 − 3)² = 4.

5 · Three functions

2 → h → −3 → g → 9 → f → 28
Example 5
h(x) = x − 5, g(x) = x², f(x) = 3x + 1. Find f(g(h(2))).
Innermost first: h(2) = 2 − 5 = −3.
Next: g(−3) = (−3)² = 9.
Last: f(9) = 3(9) + 1 = 28.

Application

Name the inner and outer function, write the composite function, then answer in a sentence.

A1A jacket costs x dollars. A coupon takes $10 off: c(x) = x − 10. A sale takes 20% off: d(x) = 0.8x. Find d(c(x)) and c(d(x)). For a $60 jacket, which order is cheaper, and by how much?
Check answer
Coupon first: d(c(x)) = 0.8(x − 10) = 0.8x − 8. d(c(60)) = $40.
Sale first: c(d(x)) = 0.8x − 10. c(d(60)) = $38.
Sale first is cheaper by $2 — for any price, because 0.8x − 10 is always $2 less than 0.8x − 8.
A2f(y) = 3y changes y yards to feet. i(t) = 12t changes t feet to inches. Find i(f(y)) and explain what it does. How many inches are in 5 yards? How many yards are 288 inches?
Check answer
i(f(y)) = 12(3y) = 36y: it changes yards straight to inches.
i(f(5)) = 180 inches (f(5) = 15 feet first).
36y = 288 → y = 8 yards.

E1g(x) = 2x + 3 and g(f(x)) = 6x − 1. f is linear. Find f(x).
Check answer
2·f(x) + 3 = 6x − 1 → 2·f(x) = 6x − 4 → f(x) = 3x − 2
Check: 2(3x − 2) + 3 = 6x − 1 ✓
E2f(x) = 2x − 1 and h(x) = −3x + 4. Show that (f ∘ h)(x) = (h ∘ f)(x).
Check answer
f(h(x)) = 2(−3x + 4) − 1 = −6x + 7
h(f(x)) = −3(2x − 1) + 4 = −6x + 7
Both are −6x + 7. This pair is special — most pairs are not equal.
E3f(x) = ax + 1 and g(x) = x + 2. Find a so that f(g(x)) = g(f(x)) for every x.
Check answer
f(g(x)) = a(x + 2) + 1 = ax + 2a + 1
g(f(x)) = ax + 1 + 2 = ax + 3
2a + 1 = 3 → a = 1
