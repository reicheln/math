Vocabulary

relation
A set of ordered pairs. It can be shown as a list of ordered pairs, a table, a mapping, or a graph.
domain
The set of all x-values (inputs) of a relation.
range
The set of all y-values (outputs) of a relation.
function
A relation where each input has exactly one output.
Formal: a function from one set (called the domain) to another set (called the range) assigns to each element of the domain exactly one element of the range.
mapping
A diagram that shows each input with an arrow to its output.
vertical line test (pencil test)
If any vertical line touches a graph more than once, the graph is not a function.
discrete
A relation made of separate, distinct points.
continuous
A relation made of connected lines or curves.
interval notation
A short way to write a set of numbers using its endpoints, like [−3, 5).

Domain = {−2, 0, 1, 4}  ·  Range = {−1, 1, 3}. List each value once. Function? Yes — every input has one output. The output 3 is used twice, and that is allowed.

2 · Is it a function?

Each input gets exactly one output. Outputs may repeat. Inputs may not.
  • Ordered pairs or table: look for an x-value that appears with two different y-values.
  • Mapping: look for an input with two arrows.
  • Graph: vertical line test. If any vertical line touches the graph more than once, it is not a function.

3 · Domain and range of continuous graphs

For domain, scan your pencil from left to right and mark every x-value where you touch the graph. For range, scan from bottom to top and mark every y-value. Write the answer with an inequality or in interval notation.

4 · Examples

Example 1 — Mapping.
Domain = {−3, 1, 4}
Range = {0, 2, 6}
Not a function: the input 1 has two arrows, to 0 and to 6.
Example 2 — Segment with an open endpoint.
Left end (−3, −2) is closed; right end (5, 2) is open.
Domain: −3 ≤ x < 5 → [−3, 5)
Range: −2 ≤ y < 2 → [−2, 2)
Function: every vertical line touches it at most once.
Example 3 — Curve with arrows.
The arrows keep going left and right forever, and down forever.
Domain: all real numbers → (−∞, ∞)
Range: y ≤ 2 → (−∞, 2]
The highest point is (−1, 2), so 2 is included.

Application

Define the variables, write the relation, find the domain and range, then interpret: discrete or continuous?

A1Movie tickets cost $12 each. A group can buy from 1 to 8 tickets. The cost is c = 12n, where n is the number of tickets.
Check answer
D = {1, 2, 3, 4, 5, 6, 7, 8}
R = {12, 24, 36, 48, 60, 72, 84, 96}
Discrete: you cannot buy 2.5 tickets.
A2A sprayer tank on a potato farm holds 600 gallons. It drains at 40 gallons per minute until it is empty. The water left is w = 600 − 40t, where t is minutes.
Check answer
The tank is empty when 600 − 40t = 0, so t = 15.
D = [0, 15] · R = [0, 600]
Continuous: time and water change smoothly.
A3(a) Input: a student at Hillcrest. Output: that student's birthday. Is this a function?
(b) Switch it. Input: a birthday. Output: a student with that birthday. Is this a function?
Check answer
(a) Function. Each student has exactly one birthday.
(b) Not a function. One birthday can belong to several students.

Extension — Green

E1Is it possible to write a relation with 4 different ordered pairs, domain {1, 2, 3}, and range {5}? Explain.
Check answer
No. The only possible pairs are (1, 5), (2, 5) and (3, 5) — just three.
E2A relation's graph is a circle with center (3, −1) and radius 4. State its domain and range. Which vertical lines touch it twice?
Check answer
D = [−1, 7] · R = [−5, 3]
Every vertical line x = a with −1 < a < 7 touches it twice.
E3Sketch a function with domain [−2, 4) and range {−1, 3}.
Sample answer
Many answers work. One: a segment at y = −1 from x = −2 (closed) to x = 1 (open), and a segment at y = 3 from x = 1 (closed) to x = 4 (open).
